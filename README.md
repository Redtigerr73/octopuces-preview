# Etiket : prévisualisation pour OctoPuces

Prototype cliquable d'un outil de gestion pour une boutique de meubles d'occasion à Bruxelles. Il réunit le stock pièce par pièce, les annonces Instagram et Marketplace, les clients, les livraisons, les paiements, la TVA sur la marge, Peppol et le stand brocante.

- **Connexion :** factice, avec le bouton « Remplir avec le compte de démo ».
- **Données :** l'identité de la boutique et les publications Instagram sont réelles, avec l'accord du commerçant. Les prix d'achat, les clients, les ventes et les paiements sont fictifs.
- **Fonctionnement :** aucun serveur. Tout reste dans votre navigateur, et « Réglages → Remettre la démo à zéro » efface tout.
- **Statut :** ce n'est pas un produit en service. Instagram, Peppol, Mollie et la banque sont simulés.

Ce dépôt est déployé par `.github/workflows/pages.yml` : tests du moteur de calcul, puis GitHub Pages.
